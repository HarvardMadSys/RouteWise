# Phase 4 Smart Hedging Experiment

Paper-used workflow for replaying Phase 1 latency profiling data and evaluating
smart hedging strategies on top of Phase 3 routing.

Run:

```bash
python -m experiments.latency_phase4.experiment --slo 3.0
```

Plot:

```bash
python -m experiments.latency_phase4.plots --results-dir experiment/results/latency_phase4
```
