# Brand Assets

`harvard-seas.svg` is the official Harvard John A. Paulson School of
Engineering and Applied Sciences logo used to identify the project's research
affiliation. `harvard-seas-wordmark.png` is a faithful rasterization of the
same artwork on a white background so it remains legible in light and dark
interfaces. The artwork itself must remain unmodified.

`routewise-routing-hero.svg` is original RouteWise project artwork. It does
not incorporate or modify any Harvard insignia.

Harvard names and insignia are not licensed under this repository's MIT
License. Their use is subject to the
[Harvard SEAS brand guidelines](https://seas.harvard.edu/office-communications/brand-style-guide/logos-templates)
and the
[Harvard Trademark Program policies](https://trademark.harvard.edu/policy-on-use-of-harvard-names-and-insignias).
